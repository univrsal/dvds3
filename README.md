## Installation

### Windows
Run the installer, or extract the `dvd-screensaver` folder from the zip into `C:\ProgramData\obs-studio\plugins`.

### macOS
Run the `.pkg` installer, or copy `dvd-screensaver.plugin` into `~/Library/Application Support/obs-studio/plugins`.

### Linux
Install the `.deb` package, or extract the `dvd-screensaver` folder from the zip into
`~/.local/share/obs-studio/plugins` (OBS Studio 33 and newer) or `~/.config/obs-studio/plugins` (older versions).
